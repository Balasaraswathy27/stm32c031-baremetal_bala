# stm32c031-baremetal_bala

Bare-metal programming on STM32 using direct register access without HAL libraries.

## Overview

This repository contains experiments and learning projects focused on low-level STM32 development using direct register manipulation. The goal is to understand how the hardware works internally instead of relying on high-level abstraction libraries.

All code is written with a focus on:

* Understanding Cortex-M architecture
* Register-level peripheral configuration
* Hardware-driven timing and interrupts
* Embedded systems fundamentals
* Bare-metal firmware development

## Environment

* Microcontroller: STM32C031C6
* Board: STM32 Nucleo-C031C6
* Language: C
* Development Style: Bare-metal / Register-level programming
* Simulation: Wokwi


## Purpose

This repository is mainly intended for learning and experimentation while building a deeper understanding of embedded systems and STM32 microcontrollers.

## Notes

* No HAL libraries are used
* Peripheral configuration is done through direct register access
* Code is written for learning and understanding hardware behavior
